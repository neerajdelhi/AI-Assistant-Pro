Privacy Policy

AI Assistant Pro respects your privacy and is committed to protecting your personal information.

Data Collection

This extension does not collect any personal data or analytics. All data is stored locally on your device.

Storage

  • API Key - Stored securely using Chrome's sync storage (encrypted)
  • Conversation History - Stored in your browser's local storage only
  • Settings - Theme preference and onboarding status

Data Transmission

The only data transmitted is:

  • Selected text when you use AI features (sent only to Google's Gemini API)
  • Your API key (used for authentication with Gemini API only)

Third-Party Services

This extension uses Google's Gemini API for AI processing. Please review Google's Privacy Policy.

Your Rights

You can clear all stored data at any time through the extension settings.

Contact

For privacy concerns, please open an issue on the project repository.
